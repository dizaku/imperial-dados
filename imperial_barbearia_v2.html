Banco de Dados no GitHub

Seus dados ficam em um arquivo JSON dentro de um repositório seu. Assim você acessa os mesmos registros de qualquer aparelho.

Desconectado

Como configurar (uma vez só)

  1. No GitHub, crie um repositório privado (ex.: imperial-dados) com um README para ele já ter a branch main.
  2. Vá em Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Em Repository access escolha Only select repositories e marque só esse repositório.
  4. Em Permissions → Repository permissions, defina Contents: Read and write.
  5. Copie o token, cole acima, preencha usuário e repositório e toque em Salvar e conectar.
  6. Em outro aparelho: abra o app, repita o preenchimento e toque em Baixar do GitHub.

O token fica salvo apenas neste navegador/aparelho (nunca dentro do arquivo de dados nem do backup JSON).
